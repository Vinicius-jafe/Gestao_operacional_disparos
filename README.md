# 🚨 Sistema de Monitoramento e Análise Preditiva de Disparos

Solução automatizada para ingestão de logs analíticos, cálculo de taxas operacionais e detecção preditiva de mau uso de alarmes.

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3.11
* **Manipulação de Dados:** Pandas, NumPy
* **Interface & Gráficos:** Streamlit, Plotly
* **Containerização:** Docker & Docker Compose
* **Integração Contínua (CI/CD):** Woodpecker CI

---
